### About the Demo

The live demo showcases an AI-powered platform designed to help engineering students identify their skill gaps and build personalized learning paths based on their **current skills, academic background, interests, career goals, and target job roles**.

Students can select a career such as **AI/ML Engineer, Data Scientist, Software Developer, Data Analyst, Cybersecurity Analyst, Cloud Engineer, or Web Developer**. The application analyzes the student's current competencies against the required skills for the selected role and generates a **priority-based learning roadmap**.
